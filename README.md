# Personal Finance Tracker

A full-stack finance tracking web application built to learn and master React through a real-world project.

---

# Tech Stack

## Frontend

- React + Vite
- React Router
- Tailwind CSS / CSS
- Axios
- Recharts

## Backend

- Node.js
- Express
- MongoDB + Mongoose

## Deployment

- Vercel (Frontend)
- Render/Railway (Backend)

---

# Features

- User authentication
- Add income & expenses
- Edit/delete transactions
- Categories
- Dashboard & analytics
- Charts and reports
- Search/filter/sort transactions
- Dark mode
- Responsive design
